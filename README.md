# SnapKart Admin Panel 🖥️ — Flutter Web Dashboard

A companion web dashboard for the [SnapKart](https://github.com/saieahmadsultan/snapkart) e-commerce app, built with Flutter Web and connected to the same Firebase backend as the mobile app.

## ✨ Features

- 🔐 **Admin authentication** — secure login for admin access
- 📊 **Dashboard analytics** — total products, orders, and customers at a glance, with weekly sales trend and category-wise product distribution charts
- 📦 **Product & inventory management** — add, edit, and manage the SnapKart product catalog, including stock and discounted pricing
- 🚚 **Order management** — view all orders with payment method, status, and date; update order status
- 👥 **Customer management** — view registered customers and their order history
- 🗂️ **Category management** — add, edit, and manage product categories
- 🎁 **Bundle offers** — manage bundled product deals
- 🔄 **Shared backend** — connected to the exact same Firebase project as the SnapKart mobile app, so changes reflect in real time

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/saieahmadsultan/snapkart-admin-panel.git
cd snapkart-admin-panel

# Install dependencies
flutter pub get

# Run on web
flutter run -d chrome
```

> Note: Connect your own Firebase project (Firestore enabled) and add the appropriate web config before running.
